# Business Insights EDA

## Project Overview

This project performs exploratory data analysis on a marketing campaign dataset to identify channel performance, ROI, conversion rates, engagement, and opportunities for better budget allocation.

## Objectives

- Analyze marketing campaign performance.
- Compare different marketing channels.
- Evaluate ROI, conversion rate, and engagement.
- Analyze the relationship between acquisition cost and ROI.
- Recommend a data-driven marketing budget allocation.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Microsoft Excel
- GitHub

## Key Findings

- **Highest ROI:** Facebook
- **Highest Conversion Rate:** Email
- **Highest Engagement:** Website
- **Acquisition Cost vs ROI Correlation:** 0.0046
- Acquisition cost has almost no linear relationship with ROI.

## Recommended Budget Allocation

| Channel | Budget |
|---|---:|
| Website | 20% |
| Facebook | 20% |
| Google Ads | 20% |
| Email | 15% |
| YouTube | 15% |
| Instagram | 10% |

## Project Files

- `Business_Insights_EDA.ipynb` — Python analysis notebook
- `Marketing_Analysis_Final.xlsx` — Final analysis results
- `marketing_campaign_dataset.csv` — Marketing campaign dataset

## Conclusion

The analysis indicates that Facebook performs best in terms of ROI, while Email has the highest conversion rate and Website has the highest engagement. Since acquisition cost has almost no relationship with ROI, increasing spending alone does not guarantee better returns. A diversified budget allocation across high-performing channels is therefore recommended.
